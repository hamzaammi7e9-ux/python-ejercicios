# Python Exercises & Projects

Este workspace contiene ejercicios y proyectos para practicar Python.

## Estructura

- **exercises/**: Ejercicios pequeños y enfocados en conceptos específicos
- **projects/**: Proyectos más grandes que combinan múltiples conceptos
- **utils/**: Utilidades y funciones compartidas
- **requirements.txt**: Dependencias del proyecto

## Cómo empezar

1. Configurar el ambiente Python:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   # o: venv\Scripts\activate  # Windows
   ```

2. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```

3. Ejecutar un ejercicio:
   ```bash
   python exercises/hello_world.py
   ```
